# 🌾 NPSS Dr.Ashif - React Native Mobile App

एक स्मार्ट कृषि और बागवानी सहायक मोबाइल ऐप्लिकेशन जो iOS और Android दोनों पर काम करता है।

## 📱 विशेषताएं

- ✅ **24/7 चैट सहायता** - तुरंत समाधान पाएं
- ✅ **कीट पहचान और नियंत्रण** - विभिन्न कीटों के लिए उपचार
- ✅ **फसल सलाह** - 100+ फसलों की जानकारी
- ✅ **बागवानी जानकारी** - फल, सब्जी और फूलों की खेती
- ✅ **हिंदी और अंग्रेजी** - दोनों भाषाओं में समर्थन
- ✅ **उत्तरदायी डिजाइन** - सभी स्क्रीन साइज़ पर अनुकूल
- ✅ **ऑफलाइन मोड** - इंटरनेट के बिना भी काम करे

## 🚀 तकनीकें

- **React Native** - iOS और Android के लिए एक कोड
- **React Navigation** - स्क्रीन के बीच नेविगेशन
- **Expo** - आसान विकास और परीक्षण
- **JavaScript ES6+** - आधुनिक JavaScript

## 📥 इंस्टॉलेशन

### आवश्यकताएं
- Node.js और npm installed
- Expo CLI installed
- Android Studio या Xcode (ऐप्लिकेशन के लिए)

### चरण

1. **रिपोजिटरी क्लोन करें:**
   ```bash
   git clone https://github.com/mohdashif6995/npss-bot-app.git
   cd npss-bot-app
   ```

2. **निर्भरताएं इंस्टॉल करें:**
   ```bash
   npm install
   ```

3. **Expo शुरू करें:**
   ```bash
   npx expo start
   ```

4. **डिवाइस पर चलाएं:**
   - iOS: Press `i`
   - Android: Press `a`

## 🎨 स्क्रीन्स

### 1. **होम स्क्रीन** 🏠
- स्वागत संदेश
- मुख्य सेवाएं (कीट नियंत्रण, फसल सलाह, आदि)
- लोकप्रिय फसलें
- त्वरित विशेषताएं

### 2. **चैट स्क्रीन** 💬
- AI चैटबॉट से बातचीत
- 10+ फसलों पर सुझाव
- कीट नियंत्रण की जानकारी
- तुरंत समाधान

### 3. **बागवानी स्क्रीन** 🌻
- फल की फसलें (7 प्रकार)
- सब्जी की फसलें (7 प्रकार)
- फूलों की फसलें (3 प्रकार)
- विस्तृत विवरण

### 4. **फसल विवरण स्क्रीन** 📊
- खेती की जानकारी
- मुख्य कीट और रोग
- नियंत्रण के तरीके
- उपयोगी सुझाव

### 5. **About स्क्रीन** ℹ️
- ऐप के बारे में
- मिशन और विजन
- डेवलपर की जानकारी
- संपर्क विधि
